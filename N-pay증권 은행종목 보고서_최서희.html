REFLECTION

익숙한 R을 벗어나며
수집을 보는 기준이 달라졌다.

R로 데이터를 수집하고 정리하는 작업이 익숙했고, 은행 데이터는 개인 컴퓨터에서 Python 자동화로 수집하고 있었다. 이번에 새롭게 경험한 것은 10월 8일에 기존 코드를 GitHub에 연결하고, 클라우드 실행과 보고까지 확장한 과정이었다.

10월 6일에는 컴퓨터가 꺼져 있어 데이터를 수집하지 못했다. 이 경험으로 자동화 코드를 작성하는 것과 그 코드가 실제로 실행될 환경을 유지하는 것은 다르다는 것을 느꼈다. GitHub 연결은 컴퓨터 상태에 의존하던 방식을 바꾸는 시도였다.

이후 백필을 실행했을 때 초록 체크가 떴지만 10월 6일 데이터는 여전히 없었다. 프로그램이 끝났다는 것과 원하는 데이터가 실제로 저장됐다는 것은 다르다. 그래서 로그와 히스토리를 함께 확인했다. 이후 ChatGPT의 도움으로 다른 조회 경로에서 찾은 10월 6일 시세를 추가했고, 최종 CSV에 11개 종목이 들어 있는지 확인했다. 다만 그날의 투자정보는 복구하지 못했기 때문에, 시세 복구와 남은 결측을 구분해 기록했다.

오후 4시 1분과 저녁 8시 10분을 고민하면서 실행 시간이 수집값의 의미와 연결된다는 것도 배웠다. 앞으로는 “자동으로 모았다”는 말보다 어떤 환경에서 실행했고, 언제 수집했으며, 어느 날짜가 누락됐는지 설명할 수 있는 수집을 하고 싶다.
